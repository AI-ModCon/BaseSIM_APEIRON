# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please use GitHub's private vulnerability reporting for this repository:

1. Go to the [Security tab](https://github.com/AI-ModCon/BaseSIM_APEIRON/security) of the repository.
2. Click **Report a vulnerability**.
3. Fill in the advisory form and submit.

This opens a private channel visible only to you and the project maintainers.

Please include the following details in your report:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

We will acknowledge receipt of your report within 48 hours and provide updates on progress towards a fix.

## Supported Versions

Apeiron is pre-1.0 and under active development. Only the most recent release line receives
security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Security Updates

We will release security updates as soon as possible after a vulnerability is confirmed. Affected users will be notified via GitHub security advisories.
